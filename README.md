# Landenex - Sitio inicial

Base inicial para una web de carteleria e impresiones profesionales.

## Archivos

- `index.html`: estructura de la landing.
- `styles.css`: estilos generales y responsivos.
- `script.js`: animacion de entrada y ano dinamico del footer.

## Como abrir

Abrir `index.html` en el navegador o usar Live Server en VS Code.

## Proximos pasos sugeridos

1. Reemplazar placeholders por fotos reales de proyectos.
2. Conectar CTA a WhatsApp o formulario backend.
3. Crear paginas internas: Servicios, Proyectos, Contacto.
4. Agregar favicon, metadatos Open Graph y analitica.
